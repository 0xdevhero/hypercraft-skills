# 🎨 /ui — HyperCraft Anti-Slop UI & Motion Design Studio

The `/ui` slash command activates HyperCraft's visual craft, modern motion, and design intelligence standards.

## Capabilities Covered:
1. **Hyper-UI-Craft:** Design modern, human-crafted dark mode UIs, Bento grids, Shimmer buttons, and spotlight cards without robotic AI tropes (`skills/hyper-ui-craft/SKILL.md`).
2. **Hyper-UI-Intelligence:** Query design tokens, curated palettes, and typography pairings (`skills/hyper-ui-intelligence/SKILL.md`).
3. **Publication-Grade Diagrams:** Create branded system architecture, sequence, and flowchart diagrams (`skills/hyper-diagram/SKILL.md`).
4. **Interactive 3D WebGL:** Three.js scenes, React Three Fiber shaders, and Spline 3D canvas models (`ecosystem/multimedia-3d/threejs-webgl/`, `ecosystem/multimedia-3d/cobe-spline-3d/`).
5. **Modern Motion Engineering:** Framer Motion spring physics, GSAP ScrollTrigger timelines, and zero-runtime Tailwind Motion (`ecosystem/multimedia-3d/framer-motion-react/`, `ecosystem/multimedia-3d/gsap-animations/`, `ecosystem/multimedia-3d/tailwindcss-motion/`).

## Agent Execution Protocol:
- Enforce clean layout hierarchy, WCAG 2.2 contrast compliance, and responsive breakpoints.
- Avoid generic AI templates (e.g., purple gradients on centered cards); enforce intentional typography, subtle borders (`border-white/10`), and physics-based easing.
