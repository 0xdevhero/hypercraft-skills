---

## Reporting a Vulnerability

If you discover a security vulnerability, weakness in an enforcement gate, or potential prompt injection attack within our skill definitions:

1. **Do not disclose the vulnerability publicly.**
2. Send an email to **security@hypercraft.dev** (or open a private security advisory on GitHub).
3. Include:
   - Skill name and specific section.
   - Attack scenario or reproduction proof-of-concept.
   - Potential blast radius on agent execution environments.

We acknowledge reports within **48 hours** and provide a timeline for patch release and disclosure.
