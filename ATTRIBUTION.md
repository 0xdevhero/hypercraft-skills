# Open Source Acknowledgements & Attribution

HyperCraft is an integrated, unified distribution of autonomous engineering capabilities, designed to establish an elite engineering standard for AI coding agents.

This project packages, consolidates, and refines concepts inspired by and built upon research and open-source contributions from the global developer ecosystem, including:

- **Agent Skills Specification**: [agentskills.io](https://agentskills.io) (Apache-2.0)
- **Specification & TDD Engineering Concepts**: Addy Osmani (Apache-2.0)
- **Anti-AI-Slop & Editorial Frontend Concepts**: Hassan El Mghari (@Nutlope) (MIT)
- **Editorial Technical & Architectural Diagrams**: Cathryn Lavery (MIT)
- **Design Intelligence & Token Taxonomies**: Next Level Builder (MIT)
- **OWASP API Security Standards**: The OWASP Foundation (Creative Commons / Open Standards)

All underlying frameworks retain their respective open-source licenses.
